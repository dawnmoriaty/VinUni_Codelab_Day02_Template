# AI Rules & Guidelines for Project

## 1. Tri thức & Quy tắc cốt lõi
- **Đọc `~/Dawn-Brain/` để tra cứu kiến thức chung, patterns, và decisions cấp tổ chức.**
- **Ghi tri thức riêng project vào `.brain/` của project này.**

## 2. Tiêu chuẩn làm việc
- Mọi quyết định kỹ thuật lớn (ADR) phải được ghi vào `.brain/decisions/`.
- Mọi ý tưởng phác thảo, brainstorming giải pháp AI lưu vào `.brain/brainstorms/`.
- Tài liệu kỹ thuật, prompt templates, spec API riêng của project lưu vào `.brain/references/`.
- Checkpoints công việc và task breakdown lưu vào `.brain/tasks/`.
